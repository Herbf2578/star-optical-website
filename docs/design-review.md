# 六頁設計對照與實作取捨

日期：2026-10-30（香港時間）。本文件記錄視覺參考如何轉換成可操作的頁面，不把原圖中的商業或醫療聲稱當作事實。實際瀏覽器檢查、截圖及修正結果另見 [測試報告](test-report.md) 與 [截圖資料夾](screenshots/)。

## 全站設計系統

六張參考圖共通的方向是海軍藍大標題、香檳金重點、暖白背景、白色卡片、照片橫幅、細分隔線與輕微陰影。新版以共用 React 元件重建導覽、頁尾、CTA、服務卡、FAQ 及流程，沒有把整張設計圖放入網頁模擬畫面。

主要色彩為 Deep Navy `#082B45`、Champagne Gold `#C8A15A`、WhatsApp Green `#20A464`、Warm White `#FAFAF8`、Light Gray `#F1F5F7` 及正文 `#334155`。實際按鈕和文字可採用較深色階，以保持可閱讀性；最終數值由 `src/app/globals.css` 統一維護。

桌面使用有限寬度的內容容器與照片／文字分區；手機把 Hero、卡片、流程、到店資訊及表單改成直向排列，配合可操作導覽與底部查詢入口。方案比較表保留可左右捲動區域；沒有靠縮小整頁適應手機。測試尺寸以驗收要求的 1440、1024、768、390、320 像素為準，是否通過請看實測記錄。

## 品牌與圖片處理

參考圖內的金藍星形標誌屬視覺概念，與目前已知原有 Logo 不同。新版保留來源網站的綠星品牌標誌，不把重新設計的星形圖案宣稱為官方新 Logo。

門市外觀及學校活動使用原有網站圖片，沒有把活動中的人物推斷成特定職銜或已驗證資格。兒童驗眼、成人試戴與鏡架靜物是原創 AI 示意圖片，頁面有相應標示，不代表真實員工、客戶、門市或實際商品。提示詞和用途見 [image-prompts.json](image-prompts.json)。

沒有把原有宣傳海報中的認證、療效、適用年齡或其他未核實聲稱裁出後另作新宣傳，也沒有把參考圖裡的錯誤電話、地址或電郵移入頁面。

## 文字與互動

全站以香港繁體中文為主，正文採較舒適行高及段落留白；大型標題、金色眉題、卡片標題與輔助說明形成層級。CTA 使用真正連結，電話採 `tel:`，WhatsApp 依服務預填並編碼，導覽、目錄篩選、FAQ 及表單均為可操作元素。

參考圖的信任區域改為實際服務與選擇指引，不展示虛構評價、星級、客人姓名、學校成果或未經核實的專業資格。查詢與預約確認清楚區分。
